# Macroeconomía Computacional con Python

Libro aplicado para aprender macroeconomía mediante simulación, datos,
visualización y modelos reproducibles en Python.

## Estructura inicial

- `book/`: configuracion Quarto e indice del libro.
- `chapters/`: capitulos en Markdown.
- `notebooks/`: notebooks ejecutables por capitulo.
- `exercises/`: ejercicios del estudiante y guia docente.
- `data/processed/`: datos derivados o simulados documentados.
- `outputs/`: tablas, figuras, reportes y entregables finales.

## Capítulo disponible

1. Del relato macroeconómico al modelo computacional.

## Nota de datos

El capítulo 1 usa datos simulados para enseñar flujo computacional. No son
observaciones reales y no deben citarse como evidencia empírica.
