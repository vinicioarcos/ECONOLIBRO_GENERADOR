# Macroeconomía Computacional con Python

Este libro enseña macroeconomía como una práctica reproducible: cada concepto
se convierte en una pregunta, cada pregunta en un modelo o conjunto de datos, y
cada resultado en una interpretación con límites claros.

## Como usar el libro

Cada capítulo incluye:

- resultados de aprendizaje;
- intuicion economica;
- formalizacion minima;
- implementacion en Python;
- figuras, tablas y reportes;
- ejercicios con guia docente;
- materiales Quarto para clase.

## Advertencia metodologica

Los ejemplos simulados sirven para enseñar mecanismos y sensibilidad de
parámetros. No representan evidencia empírica observada ni justifican
recomendaciones de política por sí solos.
