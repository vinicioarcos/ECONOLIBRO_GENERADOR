# Econometria Financiera con Python

**Modelos, riesgo, volatilidad y aplicaciones empiricas para mercados financieros**

Este libro pertenece a la Serie Econolab Computacional y usa Python para
descargar, preparar, modelar e interpretar datos financieros. El foco es
pedagogico y aplicado: precios, retornos, volatilidad, riesgo, portafolios,
modelos de factores y series financieras.

## Regla de datos

Los datos financieros se descargan desde internet usando fuentes documentadas.
Para docencia se puede usar `yfinance`; para investigacion formal se debe
registrar fecha de descarga, proveedor, ticker, periodo, ajustes y limitaciones.

## Primer entregable

El primer capitulo trabaja con precios descargados desde Yahoo Finance mediante
`yfinance`, construye retornos logaritmicos y exporta tablas/figuras
reproducibles.

## Capitulos disponibles

- Capitulo 1: datos financieros con Python.
- Capitulo 2: precios, retornos, rendimiento acumulado y drawdown.

Cada capitulo tiene PDF del entregable y diapositivas en HTML, PDF y PowerPoint
en `outputs/final`.
