# Políticas Públicas Basadas en Datos

**Diagnóstico, diseño, evaluación y comunicación de decisiones públicas con Python**

Este libro pertenece a la Serie Econolab Computacional. Su foco es formar
analistas capaces de convertir problemas publicos en preguntas verificables,
trabajar con datos administrativos y estadisticos, construir evidencia
descriptiva, distinguir prediccion de evaluacion causal y comunicar resultados
con prudencia institucional.

## Regla de datos

Los datos oficiales deben documentarse antes de usarse. `data/raw` queda intacta
y cualquier transformacion se guarda en `data/processed`. Cuando se usen datos
simulados para docencia, deben declararse como simulados y no pueden presentarse
como evidencia empirica sobre Ecuador, America Latina ni otro territorio real.

## Primer entregable

El libro queda iniciado con:

- brief editorial y pedagogico;
- indice maestro en Quarto;
- dos capitulos desarrollados;
- ejercicios y soluciones docentes para los dos capitulos;
- notebooks reproducibles con datos simulados para practicar flujos de politica
  publica sin inventar resultados reales;
- inventario inicial de fuentes oficiales para verificacion.

## Capitulos disponibles

- Capitulo 1: decisiones publicas basadas en datos.
- Capitulo 2: diagnostico de problemas publicos y priorizacion.

Los notebooks exportan tablas y figuras a `outputs` cuando se ejecutan.
