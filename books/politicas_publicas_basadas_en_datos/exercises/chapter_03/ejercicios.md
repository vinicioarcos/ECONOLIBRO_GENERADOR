# Ejercicios - Capítulo 03

## Diagnóstico

Estos ejercicios verifican que el estudiante puede construir una teoría del
cambio, separar productos de resultados y diseñar indicadores trazables sin
afirmar impacto causal.

## Producto generado

### Ejercicio 1. Cadena de resultados

Clasifique cada elemento como insumo, actividad, producto, resultado intermedio
o resultado final:

1. Presupuesto asignado para tutores.
2. Sesiones de tutoría realizadas.
3. Estudiantes que reciben al menos cuatro tutorías.
4. Aumento de asistencia mensual.
5. Reducción del abandono escolar anual.

### Ejercicio 2. Mecanismo

Formule un mecanismo plausible para una política de transporte escolar. Debe
incluir población objetivo, restricción que se quiere modificar, comportamiento
esperado y una advertencia sobre costos o implementación.

### Ejercicio 3. Indicadores

Diseñe tres indicadores para una teoría del cambio de empleo juvenil:

1. un indicador de producto;
2. un indicador de resultado intermedio;
3. un indicador de resultado final.

Cada indicador debe incluir unidad de análisis, periodo, fuente potencial y
frecuencia de medición.

### Ejercicio 4. Python

Ejecute el cuaderno del capítulo. Cambie una meta de la tabla de indicadores y
explique cómo cambia el semáforo de monitoreo. No interprete el cambio como
impacto causal.

## Justificación

La teoría del cambio exige conectar acciones, mecanismos e indicadores. Estos
ejercicios fuerzan esa conexión y reducen el riesgo de medir actividades
aisladas.

## Riesgos o limitaciones

El cuaderno usa datos simulados. Las respuestas no deben presentar resultados
como evidencia empírica de una institución real.

## Próximo paso

Aplicar la matriz a un programa real solo después de validar fuente, periodo,
cobertura, definiciones e información sensible.
