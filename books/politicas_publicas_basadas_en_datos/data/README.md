# Datos del libro

Esta carpeta contiene datos del libro `Politicas Publicas Basadas en Datos`.

## Reglas

- `raw`: datos originales descargados o recibidos. No modificar.
- `processed`: datos derivados generados por notebooks o scripts.
- `dictionary`: diccionarios de variables, bitacoras de limpieza y metadatos.

Los notebooks iniciales usan datos simulados con fines pedagogicos. Esos datos
no son evidencia empirica y no deben citarse como resultados reales.
