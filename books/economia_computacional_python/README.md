# Economía Computacional con Python

Libro base de la Serie Econolab Computacional.

Esta carpeta contiene los materiales propios del libro:

- `book/`: archivos maestros y configuración editorial.
- `chapters/`: capítulos en Markdown.
- `notebooks/`: notebooks reproducibles por capítulo.
- `exercises/`: ejercicios, soluciones y notebooks docentes.
- `data/`: datos originales, procesados, externos y diccionarios.
- `outputs/`: tablas, figuras, reportes y entregables finales.

La raíz del repositorio conserva solo infraestructura común: scripts, plantillas,
prompts, rúbricas, workflows, documentación general y archivos de configuración.
